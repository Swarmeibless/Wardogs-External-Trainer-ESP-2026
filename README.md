## ⚙️ Feature Details

### 🎯 Aimbot
- **Movement prediction** for accurate targeting
- **Target selection**: players, bots, teammates
- **Bone selection modes**: head, neck, chest, body, etc.
- **Humanize** for natural aiming behavior
- **FOV adjustment** (field of view)
- **Smoothness control** for aim transitions
- **Visibility check** (ignores targets behind walls)
- **Max distance** for aimbot range
- **Additional modes**:
  - pSilent (invisible aim)
  - Vector Aim (legit-style)
  - Teleport Bullet (instant hits)
  - Always (constant aimbot activation)

### 👁️ Player ESP
- **Boxes**: normal or corner-style, solid or gradient fill
- **Skeleton** with adjustable line thickness
- **Lines**: to enemies, view direction
- **Info display**: nickname, team, weapon, distance
- **Team colors** and visibility checks
- **Extras**: knocked players, corpses, projectiles

### 🌍 World ESP
- **Dropped items**
- **Vehicles**
- **Objects** (buildings, players)
- **Offscreen ESP** (arrows for out-of-view targets)

### ⚙️ Additional Features
- **No Recoil / No Spread / No Sway** – improved shooting
- **Fullbright** – brightens dark areas
- **Custom crosshair & binds**
- **Radars** (2D and in-game)
- **Mortar Fire Assistant** – assists with mortar targeting
- **Graphics tweaks**: disable particles, vegetation, fog, shadows
